## Candidate Boundary

whose closed fields have native types and whose nonempty rows are exact tuples
of exact integer triples. The original calendar validator and original full
TickWindow constructor validate every cold binding. Only immutable tuple/int
storage is shared; shell objects are detached. Unqualified runtime or non-native
shape follows the existing live copy path. The bounded64-binding cache remains
local to one call. No mutable account histories, callbacks, rollback mechanics,
source gates, prices, sizing, costs or statistical rules are changed.

Full population/pair/successor equality, reader/prediction ordering, malformed
input errors, original namespaces, runtime drift and cleanup must be tested.
Synthetic tests are software evidence, not strategy or real-market equivalence.
