## Implementation Boundary

`tools/nq_apex_baseline_nomination_v117.py` implements only the candidate mask and
account adapter. It retains original forecast values and original trade engines.
The small transactional phase dispatch is copied because the frozen parent's
method permits only its exact class. No locked ancestor is patched or edited.
The new adapter also rejects recursive dispatch and callback mutation of the
original account and restores its snapshot after failure/interruption. This is
a pre-market integrity correction, not a changed economic gate. The unchanged
control engine is still required to reproduce its complete saved reports.

Software tests use invented tapes only and cannot serve as economic evidence.
The component cannot fit, load market data, create claims, publish results,
deploy signals or order. A source-authenticated, preclaimed economic runner is
still required before this candidate is evaluated. This implementation alone
does not start a backtest or supersede completed V116 as the latest result.
Windows, credentials, Telegram, collectors, schedules and live/paper order
execution are outside this experiment.
