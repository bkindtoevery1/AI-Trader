# Historical Research Overview

This public overview is a publication extract dated 2026-09-27, not a replacement
for the locally retained historical protocol, source locks or account evidence.

Earlier research included multiple 25K NQ/MNQ, data-admission, multiresolution,
and prospective-validation protocols. Later user instructions changed the active
target to Legacy 50K and prioritized existing historical data. Older specifications
describe their own dated experiments; they do not silently override current scope.

The V1-V74 per-version rationale and outcome inventory has not been reconstructed
for this publication. That gap is explicit rather than filled with invented history.
Use the [V75-V119 index](RESEARCH_VERSION_INDEX.md) for the currently documented
version-by-version reasons, changes, results, aborts and deferred work.

Completed backtests, implementation checks and recorded-ledger audits must remain
distinct from independent validation, account qualification, PA survival, payout,
or realized personal profit. No verified full-route pass is claimed by this overview.

Raw/licensed data, fitted models, detailed trade/account ledgers and sealed holdout
material stay outside this public branch. See [publication scope](RESEARCH_PUBLICATION.md).
