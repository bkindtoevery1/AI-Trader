# Research Version Index

Documentation snapshot: 2026-09-27. This is a navigation aid, not a new evaluation or authorization to rerun a closed study. See [current authority](RESEARCH_CURRENT.md) for subsequent checkpoints.

## Reading The Record

- Rationales below summarize the linked contemporaneous designs, not newly inferred causes of failure. Status descriptions summarize documented results, not newly computed metrics.
- Completed execution, passing software regression, and successful ledger reconciliation are not model passes. Numerical Evaluation, PA economics, survival, and payout are separate outcomes.
- Repeated historical development is not independent validation, even with chronological splits and purges. Sealed holdout data remain excluded.
- Local reports, detailed account/trade ledgers, fitted artifacts, raw/licensed data, and secrets are excluded from this public documentation deliverable. Existing document references to local evidence do not mean that evidence is published or backed up on GitHub.
- Frozen specifications and results remain intact. Add dated completion records or errata; do not rewrite a frozen design to match its outcome. Pending execution or verification must say `NOT_RUN`.
