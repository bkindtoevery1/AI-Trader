exhausts executable capacity. V132's terminal-return vetoes do not improve the
full route. Do not invert or retune those filters. Test whether smaller actual
contract granularity from Evaluation start helps the same HGB family preserve
capacity without assuming smaller size creates an edge.

One new fixed execution policy uses MNQ forecasts and actual MNQ execution in
BOTH Evaluation and PA. Its comparator is exact V130 HGB NQ Evaluation followed
by MNQ PA. Both use each product's already-fitted HGB predictions and own tape.
This is not a new estimator fit or an isolated size ablation: changing product
also changes its own forecasts, available support, costs and account trajectory.
It is an outcome-informed whole-route policy comparison.

MNQ Evaluation is not generally new. V87-V103 tested earlier forecasts with
MNQ, and V98 tested capacity-dependent product selection. V107 instead fixes
the switch to MNQ at PA start. This comparison fixes MNQ before all outcomes,
uses retained V129/V130 HGB own-product forecasts, and makes no intraday product
ranking, NQ rescue, forecast multiplication or conditional fallback.
