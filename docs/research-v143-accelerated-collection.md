integration and external terminal hashes. The child never advances it. This
detects deletion of an otherwise consistent completed suffix, not just corrupt
individual files. Unknown artifacts, nonregular files, links, failures,
incomplete publications and missing/nonzero terminal receipts block reuse.
Run starts are exclusively claimed before source restoration. The next batch
cannot proceed merely because the child wrote its own completion JSON.

900+5,400*requested_cells seconds. This controls resource use, not scientific
population size. The first real integration invocation will append one cell;
